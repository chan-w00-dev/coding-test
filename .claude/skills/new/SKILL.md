인자로 받은 프로그래머스 문제 URL을 브라우저로 열어
제목, 난이도(Lv.), 문제 설명, 제한사항, 입출력 예시, 정답률을 읽어온다.

브라우저 연결이 없으면 사용자에게 문제 본문을 붙여넣어 달라고 요청한다.

읽어온 뒤 다음 파일들을 생성한다. 레벨 폴더는 문제 페이지에 표시된 난이도(`Lv. 0`, `Lv. 1`, ...)를
그대로 따르고, 문제 폴더명은 공백을 제거한 문제 제목으로 한다.

### 1. `programmers/lv<N>/<문제명>/problem.md`

문제 제목, 원본 URL, 정답률, 문제 설명, 제한사항, 입출력 예시를 정리해 담는다.

### 2. `programmers/lv<N>/<문제명>/tests.json`

입출력 예시를 아래 형식으로 담는다.

{
  "problem": "문제 제목",
  "url": "원본 URL",
  "accuracy": "89%",
  "cases": [
    { "input": [인자1, 인자2], "output": 기댓값 }
  ]
}

`input`은 반드시 인자 리스트다. 인자가 하나여도 리스트로 감싼다.

### 3. `programmers/lv<N>/<문제명>/solution.py`

def solution(...):
    pass

**함수 본문은 절대 채우지 않는다.** 시그니처는 문제의 입출력 예시에서 유추한다.
