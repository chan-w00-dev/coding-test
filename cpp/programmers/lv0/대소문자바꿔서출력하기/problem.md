# 대소문자 바꿔서 출력하기

- URL: https://school.programmers.co.kr/learn/courses/30/lessons/181949
- 난이도: 레벨 0
- 정답률: 79%

## 문제 설명

영어 알파벳으로 이루어진 문자열 str이 주어집니다. 각 알파벳을 대문자는 소문자로 소문자는
대문자로 변환해서 출력하는 코드를 작성해 보세요.

## 제한사항

- 1 ≤ str의 길이 ≤ 20
- str은 알파벳으로 이루어진 문자열입니다.

## 입출력 예시

### 예제 1

입력

```
aBcDeFg
```

출력

```
AbCdEfG
```
